# Chess Game ♟️

A two-player chess game built with Python and Pygame. Two players can play against each other on an interactive 8×8 chess board, taking turns to move their pieces according to the rules of chess.

## 🎮 How It Works

The game is designed for two players sharing the same computer.

- Player 1 controls the White pieces.
- Player 2 controls the Black pieces.
- Players take turns making moves.
- Each player selects a piece and moves it on the chess board.
- The game continues until the match reaches its ending condition.

## ✨ Features

- Two-player local gameplay
- Interactive 8×8 chess board
- White and Black pieces
- Turn-based gameplay
- Mouse-controlled piece selection
- Chess piece movement
- Move validation
- Capturing opponent pieces
- Interactive graphical interface

## 🎯 Objective

The objective of the game is to use your pieces strategically and checkmate the opponent's King.

Player 1 plays as **White**, while Player 2 plays as **Black**.

## 🎮 Controls

| Input | Action |
|-------|--------|
| Mouse Click | Select a chess piece |
| Mouse Click | Select the destination square |
| ESC | Quit the game |

## 🏁 How to Play

1. Start the game.
2. Player 1 (White) makes the first move.
3. Player 2 (Black) makes the next move.
4. Players continue taking turns.
5. Capture opponent pieces and try to checkmate the opposing King.
6. The game ends when the match reaches its final condition.
